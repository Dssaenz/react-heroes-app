### Installation

Requires [Node](https://nodejs.org/) v16.13.0 to run.
Requires [NPM](https://www.npmjs.com/) v16.13.0 to run.
Requires [YARN](https://yarnpkg.com/) 1.22.19 to run.

### Frontend

With yarn

```sh
$ cd react-heroes-app
$ yarn
$ yarn dev
```

With npm

```sh
$ cd react-heroes-app
$ npm install
$ npm run dev
```
